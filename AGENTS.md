## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `datashaman/mcp` using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical agent triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo: read root `CONTEXT.md` and `docs/adr/` when present. See `docs/agents/domain.md`.
